Pour Sébastien : installer ce code sur l’écran d’accueil

Version de démonstration : ce code ouvre la page explicative. Dès que le lien d’avis de la fiche Google sera ajouté au site, ce même écran affichera le vrai code, sans rien réinstaller.

iPhone

  1. Ouvrez cette page dans Safari.
  2. Touchez le bouton Partager (carré avec une flèche).
  3. Choisissez Sur l’écran d’accueil, puis Ajouter.

Android

  1. Ouvrez cette page dans Chrome.
  2. Touchez le menu ⋮ en haut à droite.
  3. Choisissez Ajouter à l’écran d’accueil ou Installer l’application.

L’icône « Avis msplomberie » apparaît alors avec vos applications. Ouvrez-la une fois avec du réseau : ensuite, le code s’affiche même sans connexion chez le client.

Astuce : montez la luminosité de l’écran avant de présenter le code. L’écran reste allumé tant que la page est ouverte.

Rappel des règles Google : proposez le code à tous vos clients, sans rien offrir en échange d’un avis.
